# Western Roguelike Prototype

A simple, turn-based roguelike prototype with a Western theme, built in JavaScript and `rot-js`.

## Controls

- **Move**: Arrow Keys
- **Aim Toggle**: `a`
- **Adjust Aim**: Left/Right Arrow Keys (while aiming)
- **Fire**: `f` (while aiming)

## Current Features

- An infinite, procedurally generated desert world.
- Turn-based movement and actions.
- A six-shot revolver with angle-based aiming and an ammo system.
- Basic enemy AI that pathfinds toward the player.
- Combat with damage calculation and enemy death. Enemies don't attack yet though.
- Visual effects for impacts (ricochets, splatters) and a persistent blood/splatter system.
- Corpses can be looted once for ammo.

## Current Objective

The game currently starts with 5 bandits. The objective is to defeat them all. The game is effectively over after they are killed.
